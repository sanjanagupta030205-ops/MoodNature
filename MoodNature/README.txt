MOODNATURE
==========

Project Name:
MoodNature – Let Nature Answer

Project Description:
MoodNature is a nature-based website that connects a person's mood
with the beauty of nature, animals, oceans, planets, and space.

Purpose:
The website provides positive and meaningful messages based on the
user's selected mood and situation.

Main Features:
1. Select a mood.
2. Enter a personal mood situation.
3. Display a suitable nature-related image.
4. Display a short poem.
5. Display a meaningful personal message.
6. Explore nature, animals, oceans, planets, and space.
7. Responsive design for desktop and mobile devices.

Technologies Used:
- HTML
- CSS
- JavaScript
- JPG Images

Project Files:
- index.html       : Main webpage
- style.css        : Website design and styling
- script.js        : Website functionality
- images/          : Website images
- README.txt       : Project information
